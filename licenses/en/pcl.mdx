### PCL Repository Fair Use Guide

> This guide is for illustration purposes only and is not a legal document or agreement.
> Except for the rights expressly granted by the PCL Distribution Limited License, the developer retains all rights in the Software and its related intellectual property. However, the developer commits that, under the condition of complying with this guide and using in good faith and reasonable manner, they will not pursue liability.

#### 1. Light Use

If you have only referenced a very small portion of the content in this repository, or if you are creating software that has no substantial functional overlap with PCL, it is considered light use.

Common examples include:
- Using or referencing a very small portion of the repository's content to develop a launcher or other software.
- Although referencing a larger amount of content, the software created has no substantial functional overlap with PCL.

If your use qualifies as light use, you need to:
1. Provide attribution in an appropriate form.
2. Not confuse your content with PCL, or imply that your content is related to PCL.
   For example: your content must not use names like Potato Craft Launcher, PCL Mobile, etc., that would cause confusion or imply a connection to PCL.

#### 2. Heavy Use

If your use does not qualify as light use, it is considered heavy use.

Common examples include:
- Modifying based on this repository.
- Referencing a larger amount of the repository's content to create or re-implement some of PCL's essential functions (such as launching or downloading Java Edition Minecraft, downloading or managing mods, etc.).

If your use qualifies as heavy use, you need to:
1. Clearly state that your content is a third-party independent derivative work based on PCL.
2. Your content's name must start with "Plain Craft Launcher (PCL)" followed by a suffix sufficient to indicate it has been modified by a third party.
   Allowed examples: PCL Server Mod, PCL PR Collection, PCL (XX Bug Fix), PCL XXX Modified.
   Prohibited examples: PCL Server Edition (implies official), PCL 3, PCL Mobile, PCL++, PCL Pro (looks like an official successor).
3. On the About page, prominently display attribution to Lone Cat and the corresponding sponsorship link, make the source code publicly available, and continue to use this file as a guide (reference CC BY-SA license).
4. If the software has Minecraft launching functionality, it should implement purchase guidance and sponsorship guidance for Minecraft that is consistent with (or more aggressive than) the McLaunchPrecheck function.
5. When running on Windows, the software should not have features or behavior similar to PCL's sponsorship unlock functionality.
   For example: the main hue of the interface must be blue (even without modification features, using a different hue is similar to the theme feature that requires sponsorship unlock).
