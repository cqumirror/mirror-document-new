## Arduino IDE 许可协议

### 主要许可

- **Arduino IDE 2.x**: AGPL-3.0
- **Arduino CLI**: AGPL-3.0
- **Arduino 核心库 (ArduinoCore-API)**: LGPL-2.1

### 许可说明

Arduino IDE 2.x 基于 Eclipse Theia 框架构建，采用 GNU Affero 通用公共许可证第 3 版（AGPL-3.0）发布。这意味着如果您通过网络向用户提供修改后的版本，必须提供源代码。

Arduino 核心库（用于编译和上传草图到开发板的部分）采用较宽松的 LGPL-2.1 许可，允许在专有项目中链接使用。
