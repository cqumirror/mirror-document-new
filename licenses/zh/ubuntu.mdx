## Ubuntu 许可协议

Ubuntu 基于 Debian 项目，遵循 [GNU 通用公共许可证 v2 (GPLv2)](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html)。

### 主要许可

- **Ubuntu 核心系统**: GPLv2
- **Ubuntu 桌面环境**: 包含多种开源许可（GPL、LGPL、MIT、Apache 2.0 等）
- **Ubuntu 仓库中的软件包**: 各软件包遵循各自的上游许可协议

### 镜像内容说明

本站提供的 Ubuntu 镜像文件（ISO）与官方镜像内容完全一致，未做任何修改。镜像文件的许可协议以 Ubuntu 官方为准。
