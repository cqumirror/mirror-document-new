## Arch Linux 许可协议

Arch Linux 是一个轻量级、灵活的 Linux 发行版，遵循极简主义设计哲学。

### 主要许可

- **Arch Linux 安装脚本和配置工具**: 以 GNU 通用公共许可证 v2 (GPLv2) 为主
- **pacman 包管理器**: GPLv2
- **Arch Wiki 文档**: 遵循 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 许可
- **官方仓库中的软件包**: 各软件包遵循各自的上游许可协议

### 镜像内容说明

本站提供的 Arch Linux 镜像文件（ISO）及软件包仓库与官方镜像内容完全一致，未做任何修改。所有内容的许可协议以 Arch Linux 官方为准。
