### Arduino 简介

Arduino 是一家意大利开源硬件和软件公司、项目和用户社区。它们设计和制造用于建造数字设备的单板微控制器和微控制器包。Arduino 板使用各种微处理器和控制器设计，配备数字和模拟 I/O 引脚，支持 USB 和串行通信接口。软件编程方面，通常使用 C/C++ 编程语言，官方提供 Arduino 集成开发环境（IDE）。
