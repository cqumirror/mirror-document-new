## openSUSE Leap Mirror Usage Guide

## URL

https://mirrors.cqu.edu.cn/opensuse/distribution/leap/

## Description

openSUSE Leap is the stable release of openSUSE, suitable for production environments and everyday use.

## Available Versions

All currently supported Leap versions.

## Usage

Back up existing repository configuration:

```bash
sudo cp -r /etc/zypp/repos.d /etc/zypp/repos.d.bak
```

Disable existing repositories:

```bash
sudo zypper mr -da
```

Add the CQU mirror:

```bash
sudo zypper ar -fcg https://mirrors.cqu.edu.cn/opensuse/distribution/leap/\$releasever/repo/oss/ CQU-OSS
sudo zypper ar -fcg https://mirrors.cqu.edu.cn/opensuse/distribution/leap/\$releasever/repo/non-oss/ CQU-Non-OSS
sudo zypper ar -fcg https://mirrors.cqu.edu.cn/opensuse/update/leap/\$releasever/oss/ CQU-Update-OSS
sudo zypper ar -fcg https://mirrors.cqu.edu.cn/opensuse/update/leap/\$releasever/non-oss/ CQU-Update-Non-OSS
```

Refresh repositories and update:

```bash
sudo zypper ref
sudo zypper up
```
