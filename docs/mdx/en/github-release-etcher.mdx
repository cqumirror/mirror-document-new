## Description

### About balena Etcher

balenaEtcher (commonly called Etcher) is a free and open-source Live USB tool for writing ISO, IMG, and ZIP image files to USB drives and SD cards to create bootable or installation media. Developed by Balena, licensed under Apache License 2.0.

## Versions

Latest version. [LatestRelease](https://mirrors.cqu.edu.cn/github-release/balena-io/etcher/LatestRelease) always points to the latest version.

## Usage

> Only exe and dmg packages are synced.

Visit the [github-release/balena-io/etcher](https://mirrors.cqu.edu.cn/github-release/balena-io/etcher/) directory to download your preferred version.
