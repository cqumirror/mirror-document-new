## Office Tool Plus Mirror Usage Guide

## Description

### About Office Tool Plus

Office Tool Plus is built on top of the Office Deployment Tool, making it easy to deploy Office. Its built-in Downloader engine helps you download Office faster. You can also use its other features and utilities to activate and manage Office conveniently.

## Supported Architectures

Same as upstream

- arm64
- x64

## Versions

Latest 3 versions. [LatestRelease](https://mirrors.cqu.edu.cn/github-release/YerongAI/Office-Tool/LatestRelease) always points to the latest version.

## Usage

> When using closed-source software, please exercise caution and only run trusted programs.

This mirror site is listed as an official download source. Visit the [official website](https://otp.landian.vip) or [help documentation](https://www.officetool.plus/zh-cn/introduction/download.html) and select "Chongqing University Mirror" to download.

### Updates

The software automatically checks for new versions on startup. Updates use the nearest download source automatically.
