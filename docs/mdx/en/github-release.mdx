## Github Release Mirror Usage Guide

## Address

https://mirrors.cqu.edu.cn/github-release/

## Description

Mirror of selected software packages and font files from GitHub Releases.

Please note that the mirror site cannot perform security audits on all software. The mirror site only provides download services — please judge the safety of software yourself and assume the associated risks.
