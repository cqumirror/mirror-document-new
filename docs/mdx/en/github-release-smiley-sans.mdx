## Description

### About Smiley Sans

Smiley Sans (得意黑) is a Chinese sans-serif typeface that balances humanistic feel with geometric characteristics. The overall glyph body is narrow and slanted, with details inspired by hand-drawn lettering. It supports simplified Chinese characters (GB/T 2312-1980 and the Table of General Standard Chinese Characters), Latin, Cyrillic, Greek, Japanese kana, Arabic numerals, and various punctuation marks.

## Usage

> `.otf` and `.ttf` files are for desktop installation — double-click and follow system prompts. `.woff2` is a web font format for web developers.

Visit the [github-release/atelier-anchor/smiley-sans](https://mirrors.cqu.edu.cn/github-release/atelier-anchor/smiley-sans/) directory to download your preferred version.
