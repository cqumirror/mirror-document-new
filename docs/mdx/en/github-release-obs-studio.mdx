## Description

### About OBS

Open Broadcaster Software (OBS) is a free and open-source cross-platform streaming and recording program developed by OBS Project. It supports Windows 10 (1809), macOS 11, and Ubuntu 18.04 or later.

## Versions

Latest version. [LatestRelease](https://mirrors.cqu.edu.cn/github-release/obsproject/obs-studio/LatestRelease) always points to the latest version.

## Usage

> Only exe, deb, and dmg packages are synced. For other versions, please visit the official website.

Visit the [github-release/obsproject/obs-studio](https://mirrors.cqu.edu.cn/github-release/obsproject/obs-studio/) directory to download your preferred version.
