## openSUSE Tumbleweed Mirror Usage Guide

## URL

https://mirrors.cqu.edu.cn/opensuse/tumbleweed/

## Description

openSUSE Tumbleweed is the rolling release of openSUSE, always providing the latest packages.

## Usage

Back up existing repository configuration:

```bash
sudo cp -r /etc/zypp/repos.d /etc/zypp/repos.d.bak
```

Disable existing repositories:

```bash
sudo zypper mr -da
```

Add the CQU mirror:

```bash
sudo zypper ar -fcg https://mirrors.cqu.edu.cn/opensuse/tumbleweed/repo/oss/ CQU-OSS
sudo zypper ar -fcg https://mirrors.cqu.edu.cn/opensuse/tumbleweed/repo/non-oss/ CQU-Non-OSS
```

Refresh repositories and update:

```bash
sudo zypper ref
sudo zypper dup
```

> **Note**: Tumbleweed is a rolling release. Use `zypper dup` (distribution upgrade) instead of `zypper up` for updates.
