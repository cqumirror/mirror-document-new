## MSYS2 Mirror Usage Guide

## URL

https://mirrors.cqu.edu.cn/msys2/

## Description

MSYS2 is a software distribution and building platform for Windows, integrating MinGW-w64 toolchain and pacman package manager.

## Usage

Edit `/etc/pacman.d/mirrorlist.mingw32` and add at the top:

```
Server = https://mirrors.cqu.edu.cn/msys2/mingw/i686/
```

Edit `/etc/pacman.d/mirrorlist.mingw64` and add at the top:

```
Server = https://mirrors.cqu.edu.cn/msys2/mingw/x86_64/
```

Edit `/etc/pacman.d/mirrorlist.msys` and add at the top:

```
Server = https://mirrors.cqu.edu.cn/msys2/msys/$arch/
```

Then refresh the package database:

```bash
pacman -Syy
```

Or use the one-liner to replace all mirror URLs:

```bash
sed -i "s#https\?://mirror.msys2.org/#https://mirrors.cqu.edu.cn/msys2/#g" /etc/pacman.d/mirrorlist*
```
