## 说明

### OBS 简介

Open Broadcaster Software（OBS）是由 OBS Project 开发的自由开源跨平台流媒体和录影程序。该程序支持 Windows 10（1809）、MacOS 11 以及 Ubuntu 18.04 以上的操作系统版本。

## 收录版本

最新一个版本，[LatestRelease](https://mirrors.cqu.edu.cn/github-release/obsproject/obs-studio/LatestRelease) 永远指向最新版本。

## 使用说明

> 仅同步 exe、deb 和 dmg 安装包，若需其他版本，请访问官网下载。

请访问镜像站 [github-release/obsproject/obs-studio](https://mirrors.cqu.edu.cn/github-release/obsproject/obs-studio/) 目录选择合适版本下载。
