## 说明

### balena Etcher 简介

balenaEtcher（通常简称为 Etcher）是一款免费开源的 Live USB 系统工具，用于将 ISO 映像和 IMG 格式文件等镜像文件以及 ZIP 格式文件写入 U 盘和 SD 卡等便携式存储介质，从而创建可启动系统或系统安装文件。它由 Balena 开发，采用 Apache License 2.0 许可发行。
