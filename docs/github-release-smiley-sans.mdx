## 使用说明

> `.otf` 和 `.ttf` 文件可用于桌面端安装，双击打开文件，按照系统提示安装即可；`.woff2` 为网页字体格式，供网站开发人员使用。

请访问镜像站 [github-release/atelier-anchor/smiley-sans](https://mirrors.cqu.edu.cn/github-release/atelier-anchor/smiley-sans/) 目录选择合适版本下载。
