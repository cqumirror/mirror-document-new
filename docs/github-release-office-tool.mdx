## 收录版本

## 使用说明

> 使用闭源软件时，请谨慎辨别，仅运行可信赖的程序。

镜像站已列入软件官方下载源，请访问[官网](https://otp.landian.vip)或[帮助文档](https://www.officetool.plus/zh-cn/introduction/download.html)选择"重庆大学镜像站"下载。

### 更新

软件启动时自动检查新版本，更新时就近选择下载源，无需手动配置。
